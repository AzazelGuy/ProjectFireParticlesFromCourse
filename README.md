# Project Fire Particles

Um projeto simples que simula uma explosão com efeito de fogo saindo do centro da tela. Feito para aprender C++ e experimentar gráficos com SDL, ele combina partículas, física básica e renderização em tempo real para criar uma animação visualmente cativante.

## Destaques

- Simulação de partículas com visual de fogo/energia
- Renderização usando SDL
- Código ideal para aprendizado e experimentação

## Por que este projeto?

É um exemplo prático para entender conceitos como:

- gerenciamento de memória em C++
- loop de jogo e atualização de frames
- manipulação de partículas e cores
- integração com bibliotecas gráficas simples

## Execute e explore

Use este projeto como ponto de partida para adicionar novos efeitos, ajustar cores, ou transformar em um pequeno jogo/interatividade.
